## Why two licences

The generator script `case_iphone13.py` is software, and software licences fit
it better, so it is under the **MIT Licence** (see `LICENSE`). Everything it
produces — the case itself — is a hardware design and is under **CC BY-SA 4.0**.

If you only want to print the case, only CC BY-SA 4.0 concerns you. If you want
to reuse the script to generate a case for another phone, MIT concerns you, and
the geometry you generate is yours.
